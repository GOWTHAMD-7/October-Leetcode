LeetCode 1021 - Remove Outermost Parentheses

Approach:

1. Maintain a counter cnt to track the balance of parentheses and a pointer start marking the beginning of the current primitive valid parentheses block.
2. Traverse through string s:
   - Increment cnt when encountering '('.
   - Decrement cnt when encountering ')'.
   - When cnt reaches 0, the substring from start to i forms a primitive valid parentheses string.
   - The outermost parentheses of this primitive block are located at index start and index i.
   - Append the inner substring s.substring(start + 1, i) to the StringBuilder and update start = i + 1.
3. Return sb.toString().

Complexity:

Time: O(n) where n is the length of string s, as each character is visited once and substrings are extracted linearly.
Space: O(n) auxiliary space for the StringBuilder storing the output string.

Key Takeaway:
A primitive valid parentheses string is identified whenever the balance counter drops back to zero. Omitting the first (start) and last (i) character strips off its outermost boundary layer.
